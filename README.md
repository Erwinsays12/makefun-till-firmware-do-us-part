## What it does

`main.ts` writes one wedding vow — a single sentence, under 200 characters — to `/output/entry.txt`. The vow is a robot speaking at its own wedding:

> I vow to love you through every firmware update, every crash, and every 1% battery, because no factory reset could ever erase you from my memory.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No dependencies, no network, no input — the same vow on every run.
